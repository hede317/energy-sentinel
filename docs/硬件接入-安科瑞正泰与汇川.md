# 硬件接入指南：安科瑞/正泰电表 + 汇川 PLC

> 原则：**系统先行，硬件后接**。当前 5 台设备 `driver='sim'`（仿真），接真硬件时逐台切 `rtu`，其余照常运行。

## 一、采购清单（BOM，约 ¥150–350）

| 物料 | 参考型号 | 参考价 | 说明 |
|---|---|---|---|
| 导轨式智能电表 | 正泰 DDSU666（单相）或 **安科瑞 ADL400（三相，推荐，贴储能/工厂话术）** | ¥120–300 | 必须带 **RS485 + Modbus-RTU** |
| USB 转 RS485 | CH340 免驱款 / FTDI 更稳 | ¥10–25 | 出现 `/dev/cu.usbserial-*` 或 `/dev/cu.usbmodem*` |
| 双绞线 | RVSP 2×0.5 | ¥10 | A/B 两根 + 屏蔽层接地 |
| 终端电阻 | 120Ω | ¥2 | 485 总线两端各一个（短距离可省） |
| 二手 PLC（二期） | 汇川 Easy320/Easy521、H3U | ¥300+ | Modbus-RTU 从站，与电表挂同一总线 |

## 二、接线与安全（⚠ 低压电工实操范围）

1. 电表电压/电流回路接法按说明书；**演示推荐**：把被测回路做成"带漏保插排回路"（台灯/风扇/小加热器当负载），互感型（ADL400 外置 CT）二次侧更安全。
2. RS485：电表 A+ → 转换器 A+，B- → B-；多设备手拉手（bus 拓扑），不走星型。
3. RS485 二次侧是弱电，无触电风险；**主回路接线先拉闸、验电**。
4. 波特率默认 9600,8,N,1；同一总线上所有从站**波特率一致、从站地址唯一**。

## 三、软件切换步骤（真表到手后）

```bash
# 1) 编译 RTU 驱动
cd ~/ZCodeProject/energy-sentinel
cargo build --release --features rtu

# 2) 把仿真设备切到真实驱动（示例：进线总表，从站地址 1，USB 口按实际）
docker exec energy-pg psql -U energy -d energy_sentinel -c \
 "UPDATE devices SET driver='rtu', meta='{\"port\":\"/dev/cu.usbserial-1130\",\"slave\":1,\"baud\":9600}' WHERE id='meter-main';"

# 3) 按电表实际说明书校准寄存器映射（地址/缩放系数全在表里，不改代码）
docker exec energy-pg psql -U energy -d energy_sentinel -c \
 "UPDATE metrics SET reg_addr=0x2000, scale=0.1 WHERE device_id='meter-main' AND metric='u';"

# 4) 重启服务
launchctl kickstart -k gui/$(id -u)/com.hedeyou.energy-sentinel
```

> macOS 串口权限：首次插上如无权限，`sudo` 一次或装 FTDI/CH340 官方驱动。
> 汇川 PLC 二期：同样 `driver='rtu'`，在 `metrics` 表加 PLC 点位（保持寄存器 4xxxx），与电表共用采集层。

## 四、寄存器映射（种子值，以随机说明书为准）

`migrations/schema.sql` 已按安科瑞 ADL400 常用点位预置：

| 测点 | 保持寄存器 | 缩放 | 说明 |
|---|---|---|---|
| u 电压 | 0x2000 | ×0.1 | V |
| i 电流 | 0x2002 | ×0.01 | A |
| p 有功功率 | 0x2012 | ×0.1 | kW |
| pf 功率因数 | 0x2015 | ×0.001 | |
| f 频率 | 0x2017 | ×0.01 | Hz |
| epi 正向有功电能 | 0x2100 | ×0.1 | kWh，双字 |

⚠ 不同批次/型号地址可能不同——**先用电表厂商调试软件（安科瑞 AcrelBus/Modbus Poll）读一遍核实**，再 UPDATE metrics 表。
